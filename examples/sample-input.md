# 输入示例（飞书机器人收到的消息）

飞书机器人收到用户发送的抖音链接，自动写入 Base 的 `原始链接` 字段。

## 示例消息

```
https://v.douyin.com/i5AbCdEfG/
```

或完整链接：

```
https://www.douyin.com/video/7123456789012345678
```

## Base 初始记录

| 字段 | 值 |
|---|---|
| 原始链接 | https://www.douyin.com/video/7123456789012345678 |
| 来源平台 | 抖音 |
| 处理状态 | pending |
| 创建时间 | 2026-08-01 10:00:00 |

Worker 下一次轮询时将领取此任务。
