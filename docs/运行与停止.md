# 运行与停止

## 启动

### 方式一：双击

双击项目根目录的 `start-xxsj-fs-ob-worker.cmd`。

调用链：

```text
start-xxsj-fs-ob-worker.cmd
→ start-xxsj-fs-ob-worker.ps1
→ scripts\start-worker.ps1
→ Worker
```

Worker 在后台运行，日志写入 `logs\worker.log` / `logs\worker.error.log`。再次双击会复用正在运行的 Worker。

### 方式二：让 AI 助手启动

Codex / Claude Code 中调用 `xxsj-fs-ob`：

```text
请使用 xxsj-fs-ob 检查 Worker 状态。如果环境正常且 Worker 尚未运行，请启动 Worker。
```

### 方式三：命令行

```powershell
.\scripts\start-worker.ps1
```

`start-worker.ps1` 不传 `RecordIds` 时是长期轮询 Worker；传入 `RecordIds` 时只处理指定记录并退出。

## 状态与监控

```powershell
.\scripts\status-worker.ps1
.\scripts\monitor-worker.ps1
```

监控读取 `data\runtime\worker-status.json`，显示状态、心跳、队列和当前阶段。关闭监控窗口不会停止 Worker。

## 停止

```powershell
.\scripts\stop-worker.ps1
```

按 `worker.lock` 中的 PID 精确停止本项目的 `run-auto-worker.ts` 进程：先写停止请求并等待，超时后只终止该 PID。

## 单次处理

```powershell
.\scripts\run-once.ps1
.\scripts\run-once.ps1 -RecordIds "recxxxxxxxx"
```

`RecordIds` 是飞书 Base 的 Record ID，不是平台作品 ID。

## 运行根

Skill 目录可以只是包装层。启动器按以下顺序解析完整项目根：

1. `-ProjectRoot`
2. `XXSJ_FS_OB_PROJECT_ROOT`
3. 启动器所在目录（须包含 `package.json`、`src`、`scripts\start-worker.ps1`）

找不到时立即失败。

## 注意

- 抖音首次使用前运行 `npx tsx scripts/manual-login.ts` 登录；
- Worker 未运行时任务停留在 `pending`；
- 电脑关机后需要重新启动 Worker；
- 不要同时启动多个 Worker；
- 未支持平台（小红书）不会被领取。
