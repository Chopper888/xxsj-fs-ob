# 运行与停止

## 日常启动方式

普通用户只保留两种启动方式。

### 方式一：让 Codex 启动

在 Codex 中选择 `xxsj-fs-ob`，然后发送：

```text
请使用 xxsj-fs-ob 检查 Worker 状态。
如果环境正常且 Worker 尚未运行，请启动 Worker。
不要修改代码和配置。完成后告诉我 PID、日志路径和停止方式。
```

Worker 启动后，不需要保持 Codex 会话开启。

### 方式二：双击 CMD 或快捷方式

双击 Skill 根目录中的：

`start-xxsj-fs-ob-worker.cmd`

或双击指向该文件的 Windows 快捷方式。

调用链：

```text
快捷方式
→ start-xxsj-fs-ob-worker.cmd
→ start-xxsj-fs-ob-worker.ps1
→ scripts\start-worker.ps1
→ Worker
```

`.ps1` 是底层技术脚本，不作为第三种普通用户启动方式宣传。

## 停止 Worker

```powershell
.\scripts\stop-worker.ps1
```

停止时不再领取新任务，当前安全步骤完成后写入恢复点并释放锁。

## 单次处理

处理一轮可领取任务：

```powershell
.\scripts\run-once.ps1
```

指定飞书 Base 的真实 Record ID：

```powershell
.\scripts\run-once.ps1 -RecordIds "recxxxxxxxx"
```

Record ID 不是平台去重 ID。

## 受控 Worker

高级用户可以按照脚本帮助使用任务上限、指定记录和空闲退出参数。例如：

```powershell
.\scripts\start-worker.ps1 -RecordIds "recxxxxxxxx" -MaxTasks 4 -IdleTimeoutSeconds 180
```

具体参数以当前脚本帮助为准。

## 启动前检查

```powershell
.\scripts\validate-skill.ps1
.\scripts\doctor.ps1
```

## 注意

- 当前正式版本只支持抖音；
- Worker 未运行时，任务会停留在 pending；
- 电脑关机后需要重新启动 Worker；
- 不要同时启动多个 Worker；
- 不要把 B站等未支持任务标记为 done。
