# 飞书权限配置

## 身份

Worker 默认使用 **bot** 身份调用 lark-cli（`LARK_IDENTITY` 未配置时为 `bot`）。

如需改为用户身份，在 `.env` 设置：

```dotenv
LARK_IDENTITY=user
```

## 需要的应用权限

在飞书开放平台为你的自建应用开通：

- `base:record:read`
- `base:record:write`（读写记录，含 upsert）
- `base:table:read`
- `base:app:read`

开通后发布应用版本，并把应用加入目标多维表格的协作者。

## lark-cli 配置

Worker 通过 lark-cli 访问多维表格，命令形如：

```powershell
lark-cli --profile <你的 profile> base +record-list --as bot --base-token <你的 Base token> --table-id <你的 table id> --format json
```

需要在 `.env` 填写：

```dotenv
LARK_PROFILE=<你的 profile 名>
FEISHU_BASE_TOKEN=<你的 Base token>
FEISHU_TABLE_ID=<你的 table id>
```

lark-cli 的安装、登录和 profile 创建命令以你本机 `lark-cli --help` 为准。

## 验证

```powershell
lark-cli --profile <你的 profile> base +field-list --as bot --base-token <token> --table-id <table id> --format json
```

能列出字段即表示权限正常。如果你的环境要求用户身份，把 `--as bot` 改为 `--as user`，同时设置 `LARK_IDENTITY=user`。

## 注意

- 不要把 App ID、App Secret、Base token、table id 提交到仓库或发到公开渠道；
- 多人共用时，每个人应使用自己的应用和 Base。
