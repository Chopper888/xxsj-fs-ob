# 升级与回滚

## 升级前

1. 停止 Worker：`.\scripts\stop-worker.ps1`
2. 备份 `.env` 和 `data/` 目录
3. `git pull` 或解压新版本

## 升级后

1. `pnpm install`
2. `.\scripts\doctor.ps1`
3. 对比 `.env` 与根目录 `.env.example`，补齐新增配置项

## 回滚

```powershell
git checkout <previous-commit>
pnpm install
.\scripts\doctor.ps1
```

不回溯用户 Obsidian 笔记。

## stage 兼容

升级后 `stage.json` 格式兼容，已有媒体与分析产物会继续复用。
