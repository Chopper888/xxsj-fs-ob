# 日志与缓存

## 日志目录
`data/logs/`

## 日志保留
- 默认保留 7 天
- 超过保留期的日志可在 cleanup dry-run 中查看

## 缓存文件
- `data/tasks/<RecordID>/media/source.mp4` - done 后保留 7 天
- `data/tasks/<RecordID>/transcript/whisper.json` - 长期保留
- `data/tasks/<RecordID>/analysis/result.json` - 临时，done 后可清理
- `data/tasks/<RecordID>/stage.json` - 运行时保留，done 后 30 天可清理

## 缓存清理预演
```powershell
.\scripts\cleanup-dry-run.ps1  # 只读，不删除
```
