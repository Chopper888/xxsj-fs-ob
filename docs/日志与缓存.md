# 日志与缓存

## 日志

- Worker 日志：`logs/worker.log`、`logs/worker.error.log`
- 启动脚本直接重定向到这两个文件；
- 代码**不做日志轮转**，也没有按天删除。需要时自行清理或使用系统计划任务。

## 任务缓存与自动清理

每条任务的数据在 `data/tasks/<RecordId>/`。Worker 每处理完一条任务后会自动执行清理：

| 对象 | 保留期 | 条件 |
|---|---|---|
| `media/source.mp4` 等媒体 | 7 天 | 任务 `done` |
| `stage.json` | 30 天 | 任务 `done` |
| 整个任务目录 | 14 天 | 任务 `failed` |
| 临时文件 | 立即 | 总是 |

处理中或缺少 `stage.json` 的目录会被跳过。

清理只影响本地缓存，不影响 Obsidian 笔记和飞书记录。

## 手动清理预演

```powershell
.\scripts\cleanup-dry-run.ps1          # 只读，列出将删除的内容
.\scripts\cleanup-dry-run.ps1 -Execute # 真正删除
```
