# 安装部署与日常使用说明

适用于第一次接触本项目的用户。仅支持 Windows 10/11。

## 1. 组成与角色

| 角色 | 作用 |
|---|---|
| 飞书机器人 | 接收你发送的平台链接 |
| 飞书多维表格 | 任务队列：一条记录就是一条任务 |
| 本地 Worker | 领取任务、下载、转写、分析、写 Obsidian |
| Obsidian | 保存最终 Markdown 笔记 |
| Codex / Claude Code | 可选，用于安装、检查和启停 |

Worker 启动后不依赖 AI 助手会话。

## 2. 支持范围

- 抖音：视频、图文（`/note/`）；不支持 v.douyin.com 短链；
- B站：BV/av、b23.tv 短链；
- 微信公众号：`/s/` 文章；
- X：status 链接、t.co 短链、纯数字 ID、图片、视频；
- YouTube：有官方字幕时稳定；无字幕视频受 CDN 限制，可能失败；
- 小红书：未实现，不会被领取。

## 3. 安装前准备

1. **Windows 10/11**
2. **Node.js 20+**、npm 或 pnpm
3. **Python 3.10+**（本地转写）
4. **FFmpeg / ffprobe**（加入 PATH）
5. **lark-cli**（飞书命令行工具，加入 PATH）
6. **飞书自建应用 + 机器人 + 多维表格**
7. **分析模型**：DeepSeek 或其他 OpenAI 兼容接口的 API Key
8. **Obsidian vault**
9. 可选：DashScope Key（Qwen-ASR）、NVIDIA GPU

## 4. 飞书多维表格字段

Worker 只写 4 个字段：`处理状态`、`知识库路径`、`处理时间`、`最近错误`。

其余字段由上游写入，表至少应包含下面 16 个字段（字段名需完全一致）：

| 字段 | 类型 | 说明 |
|---|---|---|
| 收录日期 | 日期 | 用于排序 |
| 作品发布日期 | 日期 | 用于排序 |
| 最近错误 | 文本 | Worker 写 |
| 原文链接 | 文本 | 必填 |
| 标题 | 文本 | 笔记文件名 |
| 备注 | 文本 | 不用 |
| 概述 | 文本 | 上游写 |
| 二级标签 | 文本 | 上游写 |
| 作者 | 文本 | 上游写 |
| 知识库路径 | 文本 | Worker 写 |
| 处理时间 | 日期 | Worker 写 |
| 去重ID | 文本 | 建议 `<平台>:<作品ID>` |
| 来源平台 | 单选 | 抖音 / B站 / 微信公众号 / X / YouTube |
| 三级标签 | 文本 | 上游写 |
| 处理状态 | 单选 | pending / draft_ready / done / failed / processing |
| 一级标签 | 单选 | 上游写 |

`来源平台` 留空时按「抖音」处理；写「小红书」「其他」不会被领取。

## 5. 安装

```powershell
git clone https://github.com/Chopper888/xxsj-fs-ob.git
cd xxsj-fs-ob
pnpm install
Copy-Item .env.example .env
notepad .env
```

填写 `.env` 中的必填项（每项都有中文注释）：

- `FEISHU_BASE_TOKEN`、`FEISHU_TABLE_ID`、`LARK_PROFILE`
- `OBSIDIAN_VAULT_PATH`（未填 Worker 不启动）
- `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`
- 可选：`DASHSCOPE_API_KEY`
- 需要代理时填 `XXSJ_HTTPS_PROXY` / `XXSJ_HTTP_PROXY`；留空表示不使用

然后：

```powershell
.\scripts\install.ps1
.\scripts\doctor.ps1
```

`doctor.ps1` 只提示、不阻止启动。它会检查 Node/Python/FFmpeg/lark-cli、`.env` 必填项、Obsidian 路径和代理。

## 6. 安装为 Skill（可选）

Codex 和 Claude Code 的用户级 Skill 目录不同，不要写死：

- Codex：通常 `%USERPROFILE%\.codex\skills\xxsj-fs-ob`
- Claude Code：通常 `%USERPROFILE%\.claude\skills\xxsj-fs-ob`

要求：

1. `SKILL.md` 位于 Skill 根目录，文件开头就是合法 YAML front matter；
2. 只保留一份同名 Skill；
3. 安装后重启客户端；
4. 在 Skill 选择器中实际看到 `xxsj-fs-ob` 才算成功。

也可以直接把仓库作为项目打开，让 AI 助手在项目根目录执行脚本。

## 7. 首次验证

1. 启动 Worker（双击 `start-xxsj-fs-ob-worker.cmd` 或 `.\scripts\run-once.ps1`）；
2. 给飞书机器人发送一条可访问的抖音链接；
3. 多维表格出现 `pending` 记录；
4. Worker 领取后变为 `processing`，最终 `done`；
5. `知识库路径` 指向 Obsidian 中生成的笔记。

抖音首次使用前需要登录：

```powershell
npx tsx scripts/manual-login.ts
```

扫码完成后登录态保存在 `.browser/douyin`。

## 8. 日常使用

```powershell
# 单轮处理（默认最多 4 条，处理完退出）
.\scripts\run-once.ps1

# 指定飞书 Record ID
.\scripts\run-once.ps1 -RecordIds "recxxxxxxxx"

# 长期 Worker
.\scripts\start-worker.ps1

# 状态 / 监控 / 停止
.\scripts\status-worker.ps1
.\scripts\monitor-worker.ps1
.\scripts\stop-worker.ps1
```

- 重复双击启动入口会复用已运行的 Worker；
- 关闭监控窗口不会停止 Worker；
- Worker 未运行时，任务会停留在 `pending`；
- 电脑关机后需要重新启动 Worker。

## 9. 状态与重试

| 状态 | 含义 |
|---|---|
| `pending` | 等待处理 |
| `processing` | 处理中 |
| `draft_ready` | 可继续处理 |
| `done` | 完成 |
| `failed` | 失败 |

自动重试条件：失败记录 + 平台受支持 + 次数 < 3 + 错误属于网络/超时/限流/Qwen/DeepSeek/Base 读写等可恢复类型 + 退避时间已到。

退避间隔：60 秒、300 秒、900 秒。计数在 `data/tasks/<RecordId>/stage.json`。

多数真实错误（链接无效、媒体缺失、403、依赖缺失等）不会自动重试，需要在多维表格里把 `处理状态` 改回 `pending`、清空 `最近错误` 后重跑。

## 10. 常见问题

**任务一直是 pending**

检查 Worker 是否运行、`来源平台` 是否是受支持的值、飞书权限是否正常、`lark-cli` 是否在 PATH。

**启动即退出，提示 OBSIDIAN_VAULT_PATH**

在 `.env` 填写 vault 绝对路径，例如 `D:\Obsidian\MyVault`。

**转写失败，提示 faster_whisper 缺失**

```powershell
pip install faster-whisper
```

或配置 `DASHSCOPE_API_KEY` 使用云端转写。

**X / YouTube 全部失败**

检查代理是否配置；这两个平台通常需要代理。

**小红书任务不处理**

未实现，属预期行为。

更多错误见 [故障恢复](故障恢复.md)。
