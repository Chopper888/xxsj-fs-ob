# 故障恢复

## 可恢复错误（自动重试，最多 3 次）
- 网络超时
- Qwen/DeepSeek 临时服务错误
- 下载连接超时
- Base 临时不可用

## 不可恢复错误（需人工处理）
- 配置缺失（fail-fast）
- 原始链接无效
- 视频私密/删除/需登录
- Obsidian 用户修改冲突

## 断点恢复
Worker 重启后自动检测已有产物:
- `source.mp4` 存在 → 跳过下载
- `whisper.json` 存在 → 跳过 Qwen
- `analysis/result.json` 存在 → 跳过 DeepSeek

## worker lock
```powershell
# 清理残留锁
.\scripts\stop-worker.ps1
# 或手动删除
del worker.lock
```
