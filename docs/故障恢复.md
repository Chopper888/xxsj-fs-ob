# 故障恢复

## 自动重试规则

同时满足以下条件才会自动重试：

1. `处理状态=failed`；
2. 平台受支持；
3. 本地重试次数 < 3；
4. `最近错误` 非空；
5. 错误**不匹配**终止关键词；
6. 错误**匹配**可恢复关键词；
7. 退避时间已到。

退避：60 秒 → 300 秒 → 900 秒。计数在 `data/tasks/<RecordId>/stage.json` 的 `retryCount`，不写飞书。

**可恢复关键词**：`timeout`、`timed out`、`network`、`temporar`、`rate limit`、`qwen`、`deepseek`、`base_read/write`、`lark_timeout/lark_exec`、`download_timeout/failed`、`terminated`

**终止关键词**：`unsupported`、`media_target_id_missing`、`record_id_`、`invalid url/format`、`not found`、`article_deleted`、`content_empty/invalid`、`permission`、`auth`、`verification`、`required`、`access_restricted`、`existing_note_modified`

## 需要人工处理的情况

- 链接无效、作品删除、私密或需登录；
- 媒体缺失（`media_candidate_missing`、`media_download_failed`）；
- 视频无音轨（`media_audio_probe_failed`）；
- YouTube/X 的 HTTP 403；
- 本地依赖缺失（`python.exe_failed`）；
- Obsidian 笔记被用户修改（`existing_note_modified`）。

处理方式：修正原因后，在多维表格把 `处理状态` 改回 `pending`、清空 `最近错误`，再运行 `run-once.ps1` 或等待 Worker。

## 断点恢复

Worker 重启后会复用已有产物：

- `data/tasks/<RecordId>/media/source.mp4` 存在 → 跳过下载；
- `transcript/whisper.json` 存在 → 跳过转写；
- `analysis/result.json` 存在 → 跳过分析。

## 限流

- 抖音：120 次/小时；超限自动把记录重置为 `pending`，不消耗重试次数；
- YouTube/B站：429 时延后重试。

## 锁与残留进程

```powershell
.\scripts\stop-worker.ps1
```

按 `worker.lock` 中的 PID 精确停止本项目的 Worker，不会影响其他 Node/Python 进程。不要手动启动第二个 Worker。
