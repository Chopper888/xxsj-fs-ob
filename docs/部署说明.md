# 部署说明

## 前置条件

- Windows 10/11；
- Node.js；
- Python 3.10+；
- FFmpeg 和 ffprobe；
- 飞书自建应用与机器人；
- 飞书多维表格；
- 对目标 Base 有读写权限的 bot identity；
- Qwen 和 DeepSeek 配置；
- Faster-Whisper Large-v3 本地环境；
- Obsidian Vault。

具体版本要求以项目依赖文件和 doctor 输出为准。

## 外部资源

使用者需要自行创建和配置：

1. 飞书应用；
2. 飞书机器人；
3. 飞书多维表格；
4. 模型账户和 API Key；
5. Obsidian Vault。

不要共用项目作者的 Secret、Token、Base 或私人 Obsidian 路径。

## 安装步骤

```powershell
.\scripts\install.ps1
.\scripts\validate-skill.ps1
.\scripts\doctor.ps1
```

首次配置时，从 `.env.example` 创建本地 `.env`，只在本机填写真实值。

不得提交 `.env`。

## 安装为 Codex Skill

不要盲目复制到固定目录。

先检查当前 Codex 已能正常显示的 Skill 的实际位置，再把 `xxsj-fs-ob` 安装到同一层级。

常见位置：

```text
%USERPROFILE%\.codex\skills\xxsj-fs-ob
%USERPROFILE%\.agents\skills\xxsj-fs-ob
```

只保留一份同名 Skill。

安装后完全重启 Codex，并在 Skill 选择器中确认实际出现 `xxsj-fs-ob`。

## 当前本机部署

当前本机实测安装位置：

`%USERPROFILE%\.codex\skills\xxsj-fs-ob`

正式 release：

`<YOUR_PROJECT_ROOT>\release\xxsj-fs-ob`

当前快捷方式：

`D:\下载\启动 xxsj-fs-ob Worker.lnk`

这些本机路径不得作为其他用户必须照搬的公共路径。

## 运行模式

### 单次运行

```powershell
.\scripts\run-once.ps1
```

### 指定记录

```powershell
.\scripts\run-once.ps1 -RecordIds "recxxxxxxxx"
```

### Worker

```powershell
.\scripts\start-worker.ps1
.\scripts\stop-worker.ps1
```

普通用户推荐通过 Codex 或 CMD/快捷方式启动。

## 当前权限状态

当前本机的正式飞书应用 bot identity 已完成 Base 读写验证，不需要 device-code。

公开发布版本不包含任何实际 App Secret、Token 或 API Key。

## 当前平台范围

当前只支持抖音。

公众号、B站、YouTube、推特 / X 和小红书仍属于后续规划。
