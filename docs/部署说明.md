# 部署说明

完整步骤见 [安装部署与日常使用说明](安装部署与日常使用说明.md)。本文只列部署要点。

## 前置条件

- Windows 10/11；
- Node.js 20+、npm 或 pnpm；
- Python 3.10+（本地转写）；
- FFmpeg 与 ffprobe；
- lark-cli；
- 飞书自建应用、机器人、多维表格；
- 分析模型 API Key；
- Obsidian vault。

## 安装

```powershell
pnpm install
Copy-Item .env.example .env
notepad .env
.\scripts\install.ps1
.\scripts\doctor.ps1
```

## 必需配置

- `FEISHU_BASE_TOKEN`、`FEISHU_TABLE_ID`、`LARK_PROFILE`；
- `OBSIDIAN_VAULT_PATH`（绝对路径）；
- `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。

可选：`DASHSCOPE_API_KEY`（云端转写）、`XXSJ_HTTPS_PROXY`/`XXSJ_HTTP_PROXY`（代理）。

## 运行模式

```powershell
.\scripts\run-once.ps1                              # 单轮
.\scripts\run-once.ps1 -RecordIds "recxxxxxxxx"     # 指定记录
.\scripts\start-worker.ps1                          # 长期 Worker
.\scripts\stop-worker.ps1
```

普通用户推荐双击 `start-xxsj-fs-ob-worker.cmd`。

## 平台范围

抖音（视频、图文）、B站、微信公众号、X、YouTube（官方字幕优先）已支持；小红书未实现。
